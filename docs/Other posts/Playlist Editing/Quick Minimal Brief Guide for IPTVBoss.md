The goal is here to create a simple curated list of the IPTV service you get which has like 25,000 useless channels and make it available to iptvplayer apps (UHF, smarter etc...). Trying to make this as concise as possible

# One time Steps

1. Install iptvboss from their website (on a PC or Mac)
2. Create a dropbox account
3. Go to the developer console of dropbox
4. Add a new API service
5. Give the API service all the right permissions (pretty much everything)
6. Get the KEY and SECRET from this API Service you just made
7. Open IPTVBoss, Open Settings, IPTVBoss Settings  
    a) Cloud Sync Enabled  
    b) Cloud Provider Drop Box  
    c) Fill APP KEY and APP SECERET  
    d) click Authorize

Now you have a cloud location where your playlist wil go.....

# Get your Sources

1. Click Source, Click Source Manager, Click +API
2. Put in your host, user, password , click Load Categories, click OK
3. I believe this adds your GUIDE to at the bottom half too.

# Create a simple playlist (i.e: Layout)

1. Click Layout at the top, click +
2. Give it a name , Save Layout
3. Double Click the name on the left
4. Now is the actual building basically you can create a group and add channels to it or just existing groups. The key here is to click IMPORT CHANNELS in the middle at the top and play with that, once you are done
5. Click OUTPUT at the top and Current Layout M3U and EPG,
6. Click OUTPUT and view cloud links
7. Copy that tinyurl link and use that in your iptvplayer app as an M3U link, if the fields are blank somethign is wrong with dropbox settings

You can repeating and tweaking this part as much as you like
